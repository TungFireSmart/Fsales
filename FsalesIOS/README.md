# FsalesIOS

SwiftUI starter project for the FSales mobile app.

Current scope:
- Lead list, search, detail, create, and edit.
- Quotation list, detail, and create-from-lead flow.
- In-memory sample data while the mobile data contract is being designed.
- App Intent shortcut to open the quotation workflow.

Open `FsalesIOS.xcodeproj` in Xcode and run the `FsalesIOS` scheme on an iOS 17+ simulator.
